# Magic Park Navi CSS版

GitHubのリポジトリ直下へ、このフォルダ内のファイルを全部アップロードしてください。

- app.py
- requirements.txt
- attraction_names.csv
- favorites.csv
- icon_catalog.csv

Streamlit Community Cloudの Main file path は `app.py` です。

## 変更点

- 共通画像・中途半端な画像をすべて削除
- 背景、カード、タブ、ボタンをCSSで全面変更
- GPS現在地、今いる施設、次の目的地
- 施設間ルートと到着ボタン
- 施設検索タブ
- 公式リンクは detail/数字/ の個別詳細ページだけ表示
- 個別ページを特定できない施設は一覧へ飛ばさず「公式未確認」
